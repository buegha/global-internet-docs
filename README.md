Простые пошаговые инструкции. Подойдут, даже если вы плохо разбираетесь в компьютерах: выберите своё устройство и выполняйте шаги по порядку.

## Что понадобится

- **Ваш личный ключ** — QR-код для подключения.
  Эта инструкция ключи **не выдаёт**: у каждого должен быть свой. Получите его у того, кто предоставляет вам доступ.
- **15 минут** свободного времени.
- Работающий интернет, чтобы скачать программу.

> [!CAUTION]
> **Никому не пересылайте свой ключ** и не публикуйте его в открытом доступе. Ключ — как пароль: тот, у кого он есть, сможет пользоваться вашим подключением.
