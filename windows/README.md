# Подключение на Windows

[← На главную](../README.md)

Пошаговая инструкция для компьютеров и ноутбуков с Windows 10 и Windows 11. Выполняйте шаги по порядку и не пропускайте ни одного.

> [!IMPORTANT]
> Перед началом подготовьте **свой личный ключ**: ссылку или QR-код. Эта инструкция ключи не выдаёт. Подробнее — в разделе [«Что понадобится»](../README.md#что-понадобится).

## Шаг 1. Скачайте программу

Нам понадобится **v2rayN** — бесплатная программа с открытым исходным кодом.

Найдите в таблице свой компьютер и нажмите на ссылку — скачивание начнётся само.

| Ваш компьютер | Ссылка |
|---|---|
| **Обычный компьютер или ноутбук** (процессор Intel или AMD) — так почти у всех | **[⬇️ Скачать для x64](https://github.com/2dust/v2rayN/releases/latest/download/v2rayN-windows-64-desktop.zip)** |
| Ноутбук на процессоре **Snapdragon** | [⬇️ Скачать для ARM64](https://github.com/2dust/v2rayN/releases/latest/download/v2rayN-windows-arm64-desktop.zip) |
| Старый компьютер с **32-разрядной** Windows | [⬇️ Скачать для x86](https://github.com/2dust/v2rayN/releases/latest/download/v2rayN-windows-86-desktop.zip) |

> [!TIP]
> Не знаете, какой у вас компьютер? Скачивайте **первый вариант** — он подходит почти всем.

Файл большой (около 150 МБ), поэтому скачивание может занять несколько минут.

<details>
<summary><b>Как точно узнать, какой у меня компьютер</b></summary>

1. Нажмите **правой** кнопкой мыши на кнопку **Пуск** (значок Windows внизу экрана).
2. Выберите **Система**.
3. Найдите строку **Тип системы**:
   - написано «процессор x64» — вам нужен **первый** вариант;
   - написано «процессор на базе ARM» — **второй**;
   - написано «32-разрядная операционная система» — **третий**.

![Окно «О системе», строка «Тип системы»](images/system-type-1.png)

</details>

Все версии программы можно найти на [странице релизов](https://github.com/2dust/v2rayN/releases), но обычно заходить туда не нужно.

## Шаг 2. Распакуйте и запустите программу

Программа скачивается в виде архива (zip-файла). Перед запуском архив нужно распаковать.

> [!WARNING]
> **Не запускайте программу прямо из архива.** Сначала обязательно распакуйте его, как описано ниже, иначе программа не будет работать правильно.

1. Откройте папку **Загрузки** — туда браузер сохраняет скачанные файлы.
2. Нажмите **правой** кнопкой мыши на файл **v2rayN-windows-64-desktop** (если вы скачали другой вариант, название будет немного отличаться) и выберите **Извлечь все…**
3. В появившемся окне нажмите **Извлечь**. Рядом с архивом появится обычная папка с таким же названием, и она откроется сама.
4. Откройте внутри неё папку **v2rayN-windows-64**.
5. Дважды щёлкните по файлу **v2rayN**.

   ![Распакованная папка с файлом v2rayN](images/unzip-1.png)

> [!TIP]
> Не удаляйте эту папку: в ней хранятся все настройки программы. Если захотите перенести её в другое место, переносите папку целиком и не кладите её в Program Files.

### Если появилось синее окно «Система Windows защитила ваш компьютер»

Это обычное предупреждение Windows для программ, скачанных из интернета.

1. Нажмите **Подробнее**.
2. Нажмите **Выполнить в любом случае**.

![Окно «Система Windows защитила ваш компьютер»](images/smartscreen-1.png)

## Шаг 3. Обновите программу

**Зачем:** без свежей версии программы и её «ядра» ключи нового формата не работают. Этот шаг не пропускайте.

1. Посмотрите на верхнюю часть окна программы. Если там есть кнопка **New Update** — нажмите её.
   Если такой кнопки нет — откройте меню **Help** → **Check Update**.

   ![Кнопка New Update в верхней части окна программы](images/update-1.png)

2. В открывшемся окне нажмите **Check and Update**.

   ![Окно проверки обновлений с кнопкой Check and Update](images/update-2.png)

3. Подождите, пока всё скачается и обновится. Программа может сама перезапуститься — это нормально.

   ![Обновление завершено](images/update-3.png)

## Шаг 4. Выберите настройки для России

**Зачем:** программа скачает готовые настройки, подобранные для России.

1. Откройте меню **Settings** → **Regional presets setting** → **Russia**.

   ![Меню Settings, пункт Regional presets setting, вариант Russia](images/region-1.png)

2. Подождите. Скачивание происходит не сразу и может занять несколько минут.
3. В нижней части окна найдите **Routing** и выберите в списке **RUv1-Всё**.

   ![Список Routing внизу окна, выбран вариант RUv1-Всё](images/region-2.png)

> [!NOTE]
> Если варианта **RUv1-Всё** в списке нет, значит, настройки ещё не скачались. Подождите ещё немного и откройте список снова.

## Шаг 5. Добавьте свой ключ

**Зачем:** ключ — это ваши личные данные для подключения. Без него программа не знает, куда подключаться.

Ключ может быть у вас в виде **ссылки** (текст, который начинается с `vless://`, `vmess://`, `trojan://` или `ss://`) или в виде **QR-кода**. Выберите свой вариант.

### Вариант А: ключ-ссылка

1. Скопируйте ссылку **целиком**: выделите её и нажмите <kbd>Ctrl</kbd> + <kbd>C</kbd>.
2. В программе откройте меню **Configuration** → **Import Share Links from clipboard**.
   Или просто нажмите <kbd>Ctrl</kbd> + <kbd>V</kbd> в окне программы — результат будет тот же.

   ![Меню Configuration, пункт Import Share Links from clipboard](images/add-key-1.png)

### Вариант Б: QR-код

- **QR-код открыт на экране** (например, в мессенджере). Сделайте так, чтобы он был виден на экране, и в программе выберите **Configuration** → **Scan QR code on the screen**.
- **QR-код сохранён как картинка.** В программе выберите **Configuration** → **Scan QR code in the image** и укажите файл с картинкой.

![Меню Configuration, пункты для сканирования QR-кода](images/add-key-2.png)

✅ **Должно получиться:** в списке программы появилась новая строка — это ваш ключ.

![Ключ появился в списке программы](images/add-key-3.png)

> [!CAUTION]
> **Никому не пересылайте свой ключ** и не публикуйте его в открытом доступе. Ключ — как пароль: тот, у кого он есть, сможет пользоваться вашим подключением.

## Шаг 6. Включите фрагментацию

**Зачем:** эта настройка помогает подключению не попадать под блокировки.

1. Дважды щёлкните по строке с вашим ключом (или нажмите на неё **правой** кнопкой мыши и выберите **Edit**). Откроется окно настроек ключа.
2. Найдите строку **Finalmask** и нажмите кнопку **⋮** рядом с ней. Появится поле для текста.

   ![Строка Finalmask и кнопка ⋮ рядом с ней](images/fragment-1.png)

3. Если в поле уже что-то написано — удалите это: щёлкните в поле, нажмите <kbd>Ctrl</kbd> + <kbd>A</kbd>, а затем <kbd>Delete</kbd>.
4. Скопируйте код ниже. Проще всего — кнопкой копирования: она появляется в правом верхнем углу блока с кодом, если навести на него мышь.

   ```json
   {
     "tcp": [
       {
         "type": "fragment",
         "settings": {
           "packets": "tlshello",
           "lengths": ["10-20"],
           "delays": ["5-10"],
           "maxSplit": 6
         }
       }
     ]
   }
   ```

5. Щёлкните в поле и вставьте код: <kbd>Ctrl</kbd> + <kbd>V</kbd>.

   ![Код вставлен в поле Finalmask](images/fragment-2.png)

6. Нажмите **Confirm**, чтобы сохранить.

## Не забывайте обновлять программу

Программа и её ядро часто обновляются. Без последних обновлений правильная работа не гарантируется.

- Если вверху окна появилась кнопка **New Update** — нажмите её и обновитесь, как в [шаге 3](#шаг-3-обновите-программу).
- Даже если кнопки нет, время от времени (например, раз в неделю) проверяйте обновления вручную: **Help** → **Check Update** → **Check and Update**.
